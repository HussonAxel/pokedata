The 18 standard type icons are from [partywhale/pokemon-type-icons](https://github.com/partywhale/pokemon-type-icons), licensed under MIT. The corresponding license notice is in `LICENSE`.

`stellar.svg` is a local companion icon because the source collection does not include the Stellar type.

All 19 icons include a local two-tone inset outline (dark outer edge and light inner rim) for contrast on light and dark backgrounds. The outline scales with the icon and stays within the original viewBox.
